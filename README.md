# AI 评测雷达

AI 能力评测相关资料的独立归档：Benchmark、Agent/Coding/Skill 评测、LLM-as-a-Judge、评测平台与评测审计。

- `topics/eval/YYYY-MM-DD.md`：每天一份，每条含标题、来源（网页/文档，或「据 X 上的报道」）、原文链接、要点、摘要、启示、标签与资源链接。
- 内容由「AI 前沿追踪」群里的能力评测 Agent 整理，初始数据取自 [Scoheart/ai-radar](https://github.com/Scoheart/ai-radar) 的 `eval` 主题（2026-10-24 至 2026-10-27）。
- 只收有真实链接的条目，不编造。
