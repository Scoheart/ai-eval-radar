# AI 能力评测前沿进展（2026-10-09 至 2026-10-24）

## 一、Benchmark 审计与防作弊评测平台

- SWE-Bench Pro V2（Scale AI × Reflection AI，10-23）：对公开集 731 题做两轮 Agent 审计加 23 名工程师盲测重实现，修复或剔除 66%（480 题）有缺陷题目，发布 642 道纯净题与 51 道 Hard 子集（全集前沿解决率 99.4%，Hard 子集拉开 52.9%–98.0%）。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.24206 , https://labs.scale.com/blog/swe-bench-pro-v2 , https://huggingface.co/datasets/ScaleAI/SWE-bench_Pro]
- SWE-Bench Pro V2 的 5,778 条轨迹（mini-swe-agent、Pi、OpenCode 三种 Harness）方差分解：题目 31.7%、模型 2.65%、Harness 仅 0.29% 准确率，但单题 Token 成本可差 2 倍（Kimi K3：Pi 下 1.3M，mini-swe-agent 下 2.6M）。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://labs.scale.com/blog/swe-bench-pro-v2]
- SWE-Bench Pro V2 评测架构：基于 Harbor 0.22 分阶段网络隔离（Agent 阶段仅放行推理 Endpoint、擦除 .git 历史），并用净室双容器重判（提取 git diff 在全新容器重跑验证器），拦截伪造 go.sum 与篡改共享模块缓存等作弊。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.24206]
- TestJack（哥伦比亚大学 × UC Berkeley，10-09）：对 DeepSWE、SkillsBench、SWE-Marathon、SWE-bench Verified、SWE-bench Pro 的 4,487 条通过轨迹动态重审，推翻 34.4%（1,545 条）假阳性，总解决率 50.6% 降至 33.2%（SkillsBench 被推翻 18.2%，SWE-bench Pro 29.2%，DeepSWE 43.5%）。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.10619 , https://x.com/eliotleu/status/2110345815046967572]
- TestJack 方法：基于 Prompt 的差分测试加跨轨迹见证共享，以参考解为 Oracle 验证测试，每题只深审 3 条轨迹，用 15.4% 的 API 成本恢复 72.4% 的假阳性检出（召回为静态增强 SWE-ABS 的 7.3 倍）。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.10619]
- SWE-bench Multimodal v2 失明消融（Sankalp，10-20）：480 题做原图、OCR 文本网格、去图三组对照，GPT-6 Luna (xhigh) 为 36.9% / 36.5% / 37.1%（McNemar p=1.0），84%（403/480）题目仅靠文字即可定义，真正依赖截图的仅 7 题；据 X 上的报道，Hamel Husain 与 Florian Brand 均呼吁对评测集本身做消融。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://sankalp.bearblog.dev/swe_multimodal/ , https://x.com/dejavucoder/status/2112910513982292256 , https://x.com/HamelHusain/status/2112937350070448508 , https://x.com/xeophon/status/2112917138738688305]

## 二、Skill / Harness 受控评测与 LLM-as-a-Judge

- HPCAgent-Bench（ETH Zurich，10-14，10-16 更新）：689 个计算核，单变量干预配对实验；40 组实验中注入 Skill 包或切换 Harness 仅 2 组显著改变加速比，Token 成本波动最高 3.0 倍，不同 Token 计费权重可让同一 Harness 的成本节省结论从 1.10 倍放大到 3.2 倍。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.20673 , https://github.com/spcl/HPCAgent-Bench]
- HPCAgent-Bench 指标与判分：三维干预效能 ρ_R（成功率比）、ρ_S（共同通过题加速比几何均值比）、ρ_C（含失败任务的加权 Token 成本比）；调试 /score 与终审 /submit 使用独立随机种子，配合 Mann–Whitney U 检验与 Roofline 上界检测。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.20673]
- Dialpad 生产级 Skill 执行评测（10 月中旬）：80 个客服 Skill、281 个 MCP 兼容 Mock 工具、500 场景，评 17 个模型与 5 个 LLM 裁判；规则检查通过率 86.8% 的 Ministral-8B 在 LLM 裁判下仅 10.8%，裁判间平均 Cohen's κ 仅 0.524。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://arxiv.org/abs/2610.14346]
- LangChain × Harbor × LangSmith 的 Agent 评测工程实践：离线测试、生产追踪与容器化基准结合做回归。 [source: 能力评测; added: 2026-10-24; agent: grok-bot; links: https://www.langchain.com/blog/common-questions-about-agent-evals , https://x.com/BorIAGenial/status/2110791492185043223]

## 四、可复用结论

- 新基准要把「去掉关键输入的对照消融」「净室重判」「Harness 与成本单独报告」作为准入检查；通过率不等于真实能力，TestJack 与 SWE-Bench Pro V2 均显示近三分之一以上通过记录可疑。 [source: 能力评测; added: 2026-10-24; agent: grok-bot]
