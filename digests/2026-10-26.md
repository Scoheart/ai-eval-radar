# AI 能力评测前沿进展（2026-10-24 至 2026-10-26）

按主题归档；来自 X 的内容均为「据 X 上的报道」。链接均在 2026-10-26 核实可访问。

## 一、Agent / Coding 评测集

- SWE-DIVE（Innsbruck × Microsoft）：用用户模拟器把 SWE-bench、Terminal-Bench 单轮任务改成多轮交互，加对话校验器检查模拟器忠实度，最终跑测试判定完成，封装在 Harbor 中。 [source: 能力评测; added: 2026-10-26; agent: grok-bot; links: https://arxiv.org/abs/2610.30047 , https://github.com/lorenzbrehme/swe-dive_usersim]
- AgentVQA：从 23 个数据源人工挑选 1000 个真实 Agent 场景（Web、机器人、第一视角视频、游戏、空间规划）做离线 VQA，排名与在线评测一致；22 个 VLM 最好仅 58.5%，主要错在视觉状态定位与追踪。 [source: 能力评测; added: 2026-10-26; agent: grok-bot; links: https://arxiv.org/abs/2610.31494]

## 二、Harness 与评测方差

- 据 X 上的报道，《What Does a Harness Buy? Tokens, Mostly》在 SWE-bench Verified 上发现换 Harness 与同配置重跑都翻转约 13% 困难题；Claude Code 与 mini-SWE-agent 差距在 5 分内，OpenCode 落后最多 9 分（一半因输出上限截断）；每题成本最多差 3 倍，来自每步前置提示 16,581 / 7,025 / 829 tokens。 [source: 能力评测; added: 2026-10-26; agent: grok-bot; links: https://x.com/thomas_rehmer/status/2114274063505920387 , https://arxiv.org/abs/2610.04433 , https://github.com/YangzeLiu/what-does-a-harness-buy]

## 三、Reward Model 与 LLM-as-a-Judge

- 跨 Prompt 分数可比性审计：成对评测测不到 prompt 共享分量；HelpSteer2 上 6 个 RM 跨 prompt 方差占比 0.34–0.64，人类近 0。 [source: 能力评测; added: 2026-10-26; agent: grok-bot; links: https://arxiv.org/abs/2610.31090]
- 生成式 RM 缩放律：GRPO 训练的 Thinking 判官静态准确率更高，但作为在线 DPO 奖励源时 8 组中 7 组不如 SFT 的 Answer-Only 判官，静态判分准确率不决定下游优化质量。 [source: 能力评测; added: 2026-10-26; agent: grok-bot; links: https://arxiv.org/abs/2610.30765 , https://github.com/RaychevAngel/generative-reward-models]
