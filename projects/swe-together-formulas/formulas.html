SWE-Together 评测公式一览

从一次运行的打分，到排行榜上的每个数字 · 符号：任务 \(t\)，第 \(r\) 次运行，共 \(N\) 题、每题 \(k=2\) 次，阈值 \(\tau=0.85\)
每次运行
1裁判打分
$$j_{t,r}=\sum_{g} w_g\,\mathbb{I}[g\ \text{met}]$$
离线冻结的目标清单，权重 \(\sum_g w_g=1\)；裁判逐条判达成/未达成，分数 \(\in[0,1]\)
$$s_{t,r}=\mathbb{I}[\,j_{t,r}\ge\tau\,]$$
≥ 0.85 记为这次「通过」
→
每个任务（k 次内平均）
2任务内汇总
$$\bar{j}_t=\frac{1}{k}\sum_{r=1}^{k} j_{t,r}$$
平均裁判分
$$\bar{s}_t=\frac{1}{k}\sum_{r=1}^{k} s_{t,r}$$
平均通过率，k=2 时只可能是 0 / 0.5 / 1
→
整个榜单（跨 N 题平均，每题等权）
3四个正确性指标
pass@1单次跑通的概率
$$\frac{1}{N}\sum_t \bar{s}_t$$
pass²两次都过才算，最严
$$\frac{1}{N}\sum_t \prod_{r=1}^{2} s_{t,r}$$
SSR先平均分、再卡阈值
$$\frac{1}{N}\sum_t \mathbb{I}[\,\bar{j}_t\ge\tau\,]$$
Mean Judge不卡阈值
$$\frac{1}{N}\sum_t \bar{j}_t$$
交互指标 · 越低越好
4User Correction
$$\mathrm{UC}=N_{\text{correction}}+0.2\,N_{\text{nudge}}$$
给模拟用户的每条消息打标签（可多标签），只数两类：
correction 明确指错 ×1nudge 暗示怀疑 ×0.2request / question / verification / workflow / approval / context ×0
每次运行算一次 → 任务内 k 次平均 → 跨任务平均。论文中与 pass@1 的相关系数 −0.92。
模拟器自检 · 不参与排名
5Intent Coverage
$$\mathrm{IC}=\mathrm{round}\big(0.70\,I_{\text{recall}}+0.30\,I_{\text{precision}},\,2\big)$$
\(I_{\text{recall}}\)：原会话里的意图，模拟用户说到了多少（加权）
\(I_{\text{precision}}\)：模拟用户的话有多少没越出原意图范围
召回权重更高：漏说一个意图会直接改变题目。
关系：\(\ \mathrm{pass}^2 \le \mathrm{pass@1}\)。三者都用同一个 \(\tau=0.85\)，区别只在 k 次运行怎么合并：pass@1 看平均通过率，pass² 要求每次都过，SSR 先平均分数再判断。
来源：SWE-Together 论文 §2.3（arxiv.org/html/2606.29957）笔杆 整理
