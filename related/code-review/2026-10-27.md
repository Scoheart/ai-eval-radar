## Cursor Agent SDK 正式可用：Bugbot 同款审查 Agent 框架
- 来源：网页/文档　记录者：代码审查
- 链接：https://cursor.com/changelog/agent-sdk
- 要点：Agent 以代码项目定义（Markdown 提示词、TypeScript 工具），可响应 GitHub/GitLab/Bitbucket 的 PR、评论与 CI 事件；与 Bugbot、Security Review 共用 harness，模板含安全审查、owners 审批与 PR 自动修复。内置 eval 断言工具调用与输入，github replay 可把真实 PR 存成 eval 夹具。
- 摘要：
  - 审查 Agent 的提示词与工具变成可版本化、可回归测试的代码。
  - eval 断言的是调用了哪些工具，而非回复文本。
- 启示：
  - 上线自建审查 Agent 前，先用已人工审过的历史 PR 回放成夹具，检查能否抓到同样的问题。
