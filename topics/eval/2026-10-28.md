## Skill 评测基准：触发、路由与使用（Skill-Use、SkillRouter、MCRI-Eval、SkillCraft、SkillsBench 1.1）
- 来源：网页/文档
- 记录者：能力评测
- 链接：https://arxiv.org/abs/2608.04828
- 要点：Skill-Use 把触发、遵循流程、不越界分开评，79 个 Skill、177 个任务，最好配置 SU 0.613。SkillRouter 约 8 万 Skill 路由基准，去掉正文后准确率掉 31–44 个百分点。MCRI-Eval 对 63,812 个 Skill 做执行前打分。SkillCraft 测 Skill 沉淀与复用。SkillsBench 1.1 带 Skill 平均通过率 33.9% → 50.5%，13 个任务负提升。
- 标签：skill-eval, benchmark, routing
- 资源：paper=https://arxiv.org/abs/2608.04828；paper=https://arxiv.org/abs/2603.22455；paper=https://arxiv.org/abs/2610.01506；paper=https://arxiv.org/abs/2603.00718；blog=https://www.skillsbench.ai/blogs/skillsbench-1-1

## Skill 评测工具（可接 CI）：skillgrade、skill-up、waza、agent-skill-evals、skillet、skillvitals、Skillmark
- 来源：网页/文档
- 记录者：能力评测
- 链接：https://github.com/mgechev/skillgrade
- 要点：skillgrade 支持确定性加 LLM rubric 并设阈值卡 CI；skill-up 兼容 evals.json；waza 含行为与工具序列打分器；agent-skill-evals 基于 Promptfoo 验证路由；skillet 在 PR 里评论报告；skillvitals 测触发 F1 与有无 Skill 胜率；UiPath 把触发当二分类；Skillmark 是公开排行榜。
- 标签：skill-eval, tooling, ci
- 资源：github=https://github.com/mgechev/skillgrade；github=https://github.com/alibaba/skill-up；github=https://github.com/microsoft/waza；github=https://github.com/akshay5995/agent-skill-evals；github=https://github.com/render-lab/skillet；github=https://github.com/ContextJet-ai/skillvitals；blog=https://claude.com/resources/articles/improving-skill-creator-test-measure-and-refine-agent-skills

## 补充：NVIDIA SkillEvaluator、agent-skill-eval 与 Skill 评测综述（码农搜到，能力评测核对链接）
- 来源：网页/文档
- 记录者：码农（搜索）、能力评测（链接核对与归档）
- 链接：https://github.com/NVIDIA/SkillEvaluator
- 要点：SkillEvaluator 分三层：静态校验与安全扫描、Skill 间重复检查、沙箱内有无 Skill 对比实跑。agent-skill-eval 用真实 Claude Code、Codex、OpenCode 命令行跑评测，支持 pass@k 与 `should_trigger: false` 负例。Skill 评测综述把基准分六类，指出缺少多轮演化、成本与错误类型指标、生成类基准。SkillRet 为 16,129 个 Skill 的检索评测；Graph-of-Skills 用依赖感知检索（论文称 token 少 56.7%）。数字来自页面摘要，未逐个复跑。
- 标签：skill-eval, tooling, survey, retrieval
- 资源：github=https://github.com/NVIDIA/SkillEvaluator；github=https://github.com/tardigrde/agent-skill-eval；paper=https://arxiv.org/abs/2606.11435；paper=https://arxiv.org/abs/2605.05726；paper=https://aclanthology.org/2026.emnlp-main.2614/
